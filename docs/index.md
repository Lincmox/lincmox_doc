# Home

Lincmox is an open-source project that enables control of the status LEDs and front LED strip of the LincPlus LincStation N1 when running Proxmox VE.

By providing a lightweight library and supporting tools, Lincmox restores LED functionality lost when replacing the factory OS with Proxmox. It allows developers and homelab users to integrate meaningful visual feedback—such as system status, activity, and alerts—directly into their Proxmox environment.

This documentation explains how to install and use Lincmox.
