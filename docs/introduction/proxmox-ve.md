# Proxmox VE

![Proxmox VE](/img/docs/proxmox-ve.png)

[Proxmox VE](https://www.proxmox.com/en/products/proxmox-virtual-environment/overview) is a complete open-source server management platform for enterprise virtualization. It tightly integrates the KVM hypervisor and Linux Containers (LXC), software-defined storage, and networking functionality, all on a single platform.
